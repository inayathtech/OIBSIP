# Sales Prediction Using Machine Learning

## Internship
Oasis Infobyte Internship - Data Science

## Project Overview
This project predicts sales based on advertising expenditure
on TV, radio, and newspaper using machine learning.

## Dataset
The Advertising dataset contains the following columns:
- TV
- radio
- newspaper
- sales

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Machine Learning Models
1. Linear Regression
2. Random Forest Regressor

## Project Workflow
1. Loaded and explored the dataset.
2. Checked missing values and duplicate rows.
3. Visualized sales and advertising relationships.
4. Analyzed correlations.
5. Split data into training and testing sets.
6. Trained two regression models.
7. Evaluated the models using MAE, RMSE, and R2 score.
8. Compared model performance.
9. Predicted sales using example advertising expenses.

## Evaluation Metrics
- MAE: Mean Absolute Error
- RMSE: Root Mean Squared Error
- R2 Score: Coefficient of Determination

## Conclusion
The project demonstrates how machine learning can estimate
sales from advertising expenditure. The models were compared
using evaluation metrics to identify the better-performing model.
